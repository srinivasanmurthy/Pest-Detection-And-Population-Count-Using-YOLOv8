# Pest Detection and Population Count Using Deep Learning Techniques

## Overview

This project presents an intelligent pest detection and population counting system for agricultural applications using Deep Learning techniques. The system automatically detects crop pests, counts the pest population, and provides severity-based recommendations for farmers.

The project utilizes Grounding DINO for automatic annotation generation and YOLOv8 for pest detection and population counting.

---

## Objectives

* Detect agricultural pests automatically.
* Count the number of pests present in an image.
* Reduce manual monitoring efforts.
* Provide pest management recommendations.
* Assist farmers in making timely decisions.

---

## Methodology

### 1. Image Collection

Pest images were collected from publicly available agricultural datasets and image repositories.

### 2. Automatic Annotation

Grounding DINO was used to automatically generate bounding boxes around pest objects.

### 3. Label Conversion

Generated annotations were converted into YOLO format (.txt files).

### 4. Dataset Preparation

Annotated images and labels were organized into train, validation, and test sets.

### 5. Model Training

YOLOv8 was trained using the prepared dataset for pest detection and population counting.

### 6. Prediction and Advisory

The trained model detects pests, counts the pest population, and provides recommendations based on severity levels.
